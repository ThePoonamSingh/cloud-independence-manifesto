# Cloud Independence Manifesto

build an interactive editorial experience.

Why? Because your audience isn't just developers anymore.

Your audience is:

Journalists looking for a story

Analysts looking for a category

CTOs looking for a point of view

SIs looking for strategic direction

Developers looking for something to believe in

The page should feel like Apple introducing the iPhone, Stripe introducing economic infrastructure, or Vercel introducing the Frontend Cloud—not a product microsite.

Below is the prompt I'd give Lovable.

MASTER PROMPT

Build an award-worthy, editorial-quality interactive storytelling website for Catalyst 3.0.

This is NOT a product landing page.

This is a manifesto, a thought leadership piece, and a digital magazine experience announcing a new era of cloud computing.

The page must feel like Apple's product launches, Linear.app, Stripe Sessions, Vercel's AI pages, Framer's storytelling pages, and Notion's editorial microsites.

The experience should be cinematic.

The user should feel like they are reading the future of software.

Every scroll should reveal another insight.

Animations should be subtle, premium and purposeful.

Never gimmicky.

No carousels.

No marketing clichés.

No "book a demo" every two sections.

The page should be memorable enough that journalists bookmark it and developers share it.

GOAL

The page should establish two new ideas:

Cloud Independence (movement)

Agent-Ready Cloud (technology category)

Catalyst is not the hero.

The future is.

Catalyst simply happens to be the platform built for that future.

TARGET AUDIENCE
